# Foothold web

The website for [Foothold](https://github.com/Napster653/foothold), a sandbox
game about building a forward operating base. For now it's the roster: every
structure, unit and mission by base level, with what unlocks what.

Served by GitHub Pages from `main` at https://napster653.github.io/foothold-web/.

`index.html` is generated: don't edit it here. In the game repo, run
`bash tools/roster.sh`, then `bash tools/publish_web.sh`.
